# PlantERA

PlantERA is a desktop provisioning and management tool for ESP32-based plant care devices.

## Current features

- ESP32 detection
- Device UID generation
- COM port selection
- Device information display
- Provisioning UI
- PySide6 interface

## Tech stack

- Python
- PySide6
- QtAwesome
- pyserial
- esptool

.\.venv\Scripts\Activate.ps1
